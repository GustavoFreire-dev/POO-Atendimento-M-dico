# SISTEMA DE ATENDIMENTO MÉDICO — 1ª ENTREGA

PROJETO ACADÊMICO EM JAVA 17, MYSQL 8, MAVEN E JDBC. TODOS OS REGISTROS SÃO FICTÍCIOS.

## PRÉ-REQUISITOS
- JDK 17 OU SUPERIOR
- MAVEN 3.9 OU SUPERIOR
- MYSQL 8 (SERVIDOR EM localhost:3306)
- VS CODE COM EXTENSION PACK FOR JAVA (OPCIONAL)

## COMO EXECUTAR
1. INICIE O SERVIDOR MYSQL. NO TERMINAL, NA PASTA RAIZ DO PROJETO:
   `mysql -u root -p < banco/schema.sql`
   `mysql -u root -p atendimento_medico < banco/dados.sql`
   ALTERNATIVA: ABRA OS DOIS SCRIPTS NO MYSQL WORKBENCH E EXECUTE-OS NESSA ORDEM.
2. COPIE `src/main/resources/db.properties.example` PARA `src/main/resources/db.properties`.
3. ALTERE `db.usuario` E `db.senha` COM AS CREDENCIAIS LOCAIS DO MYSQL.
4. EXECUTE `mvn compile exec:java -Dexec.mainClass=br.edu.unifacisa.atendimento.Main`.
5. VERIFIQUE A MENSAGEM DE CONEXÃO, A LISTAGEM DE 6 USUÁRIOS, 4 CONSULTAS E A VALIDAÇÃO DE SENHA.

## ARQUIVOS IMPORTANTES
- `banco/schema.sql`: CONTRATO EXATO DAS TABELAS COM A API REST.
- `banco/dados.sql`: 1 SECRETÁRIA, 2 MÉDICOS, 3 PACIENTES E 4 CONSULTAS.
- `docs/diagrama-classes.png`: UML COM HERANÇA, ASSOCIAÇÕES E ENUMS.
- `src/main/java/br/edu/unifacisa/atendimento/Main.java`: LEITURA COM PREPAREDSTATEMENT E TRY-WITH-RESOURCES.
- `src/main/resources/db.properties.example`: EXEMPLO SEM CREDENCIAIS REAIS.

## ESCOPO
ATENDE À PRIMEIRA ENTREGA (RF01–RF04, RN01–RN02, RNF01–RNF04). CRUD, DAO, SERVICE, REGRAS RN03–RN08 E TESTES JUNIT SÃO PARA A SEGUNDA ENTREGA.

## OBSERVAÇÕES
- A UNICIDADE DE EMAIL É GARANTIDA NO MYSQL; A NORMALIZAÇÃO PARA MINÚSCULAS É FEITA EM JAVA.
- A PRIMEIRA ENTREGA ADMITE SENHAS DEMONSTRATIVAS EM TEXTO NO `dados.sql`; NÃO UTILIZE ESSAS SENHAS EM PRODUÇÃO.
- `db.properties` É IGNORADO PELO GIT. NÃO PUBLIQUE SENHAS REAIS.
- O SCRIPT `dados.sql` É DESTINADO A UM BANCO NOVO; REEXECUTÁ-LO EM UM BANCO COM DADOS EXISTENTES PODE GERAR CONFLITOS.
- O PROJETO NÃO FOI VALIDADO CONTRA UM SERVIDOR MYSQL REAL NESTE AMBIENTE.
